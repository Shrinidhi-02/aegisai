# AegisAI

## AI Security Gateway

AegisAI is an open-source defensive security gateway designed to protect
company AI applications and LLM-based systems from common AI security threats.

AegisAI sits between a company's application and its AI model.

```text
User
  |
  v
Company AI Application
  |
  v
AegisAI
  |
  +--> Input Security Scan
  |
  +--> Policy Engine
  |
  v
AI Model
  |
  v
AegisAI
  |
  +--> Output Security Scan
  |
  v
Safe Response
  |
  v
User
```
